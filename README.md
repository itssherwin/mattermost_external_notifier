# Mattermost External Notifier

Mattermost server plugin that watches configured teams/channels, extracts `@username` mentions, looks up each username in a CSV file, and sends one external HTTP POST notification for every matched user.

## Requirements

- Mattermost Server 10.0 or newer
- Go 1.24 or newer for building
- A CSV mapping Mattermost usernames to notification numbers
- An HTTP/HTTPS endpoint that accepts the notification payload

## How it works

1. Mattermost calls `MessageHasBeenPosted` when a post is created.
2. The plugin resolves the post's channel with `GetChannel(post.ChannelId)`.
3. The channel provides the `TeamId`; `model.Post` itself does not contain `TeamId`.
4. The configured team and channel filters are evaluated.
5. User mentions are extracted from the message.
6. `@all`, `@channel`, and `@here` are ignored.
7. Duplicate usernames in the same post are sent only once.
8. Each username is looked up in `data.csv`.
9. A matching number receives an asynchronous HTTP POST.
10. The HTTP response must be 2xx for the request to be considered successful.

## Configuration

Configure these values in the Mattermost System Console plugin settings.

### Enabled

Enable or disable the plugin.

### Team IDs

Comma-separated Mattermost team IDs.

Empty means all teams.

### Channel IDs

Comma-separated Mattermost channel IDs.

Empty means all channels.

If both Team IDs and Channel IDs are configured, a post must match both filters.

### Notification endpoint

Example:

```text
https://notifications.example.com/mattermost
```

Only `http` and `https` URLs are accepted.

### Bearer token

Optional. When configured, the request contains:

```text
Authorization: Bearer YOUR_TOKEN
```

### CSV path

Default:

```text
data.csv
```

Relative paths are resolved relative to the plugin executable.

### HTTP timeout

Default:

```text
10
```

Allowed range:

```text
1-120 seconds
```

## CSV format

The recommended format is:

```csv
username,number
alice,0901234567
bob,0909876543
charlie,0912345678
```

A leading `@` is also accepted:

```csv
username,number
@alice,0901234567
@bob,0909876543
```

The username lookup is case-insensitive.

A header is optional. The loader recognizes common headers such as:

```text
username,number
user,phone
name,phone_number
```

Malformed rows and rows without both values are skipped.

## Notification payload

For a post containing:

```text
Please check this @alice
```

and a CSV mapping:

```csv
username,number
alice,0901234567
```

the endpoint receives approximately:

```json
{
  "name": "alice",
  "number": "0901234567",
  "post_id": "post-id",
  "user_id": "author-id",
  "team_id": "team-id",
  "channel_id": "channel-id",
  "message": "Please check this @alice"
}
```

The request method is:

```text
POST
```

with:

```text
Content-Type: application/json
```

## Mention behavior

Supported examples:

```text
@alice
hello @alice
hello @Alice
(@alice), please review this
```

Ignored:

```text
@all
@channel
@here
alice@example.com
```

Repeated mentions are deduplicated:

```text
@alice please help @alice
```

produces one notification for `alice`.

## Build

Install Go 1.24 or newer and run:

```bash
go mod tidy
```

Then:

```bash
make check
```

Build:

```bash
make build
```

Package:

```bash
make package
```

The package is written to:

```text
dist/rocks.sherwin.mention-notifier-v0.2.0.tar.gz
```

## Network problems during `go mod tidy`

If `proxy.golang.org` is unavailable in your environment, try:

```bash
GOPROXY=direct go mod tidy
```

Do not manually create `go.sum`. It should be generated by Go after the dependency is successfully downloaded.

## Installation

Build the package:

```bash
make package
```

Install the generated plugin archive through the Mattermost System Console or your normal Mattermost plugin deployment process.

After installation:

1. Upload/enable the plugin.
2. Configure the endpoint.
3. Configure team/channel filters.
4. Make sure `data.csv` is available beside the plugin executable or configure an absolute CSV path.
5. Enable the plugin.
6. Post a message containing a configured username mention.

## Security

- Use HTTPS for the notification endpoint.
- Do not commit real bearer tokens.
- Do not commit production phone/notification numbers unless your repository is appropriately protected.
- Keep `data.csv` out of version control if it contains sensitive data.
- Restrict the external endpoint so it accepts requests only from trusted infrastructure when possible.
- The plugin logs failures but does not log the notification number on successful requests.

## Troubleshooting

### Missing `go.sum`

Run:

```bash
go mod tidy
```

If the dependency download times out:

```bash
GOPROXY=direct go mod tidy
```

### `post.TeamId undefined`

Do not add `TeamId` to `model.Post`.

The plugin deliberately resolves the team like this:

```go
channel, appErr := p.API.GetChannel(post.ChannelId)
teamID := channel.TeamId
```

### No notification is sent

Check:

- Plugin is enabled.
- Team ID matches.
- Channel ID matches.
- Mentioned username exists in the CSV.
- CSV path is correct.
- Notification endpoint is reachable.
- Endpoint returns a 2xx status.
- Mattermost plugin logs for errors.
